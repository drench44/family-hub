# To-Do List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shared household to-do list (Now / Soon / Later buckets, no people linkage, items carry over until done) with a compact wall card, a full-screen view, and a phone tab.

**Architecture:** New `todos` table + plain-function CRUD in `db.py`; a pure stdlib logic module `todos.py` (visibility + grouping, mirroring `chores.py`); REST endpoints in `app.py` plus a `todos` key in `/api/hub`; vanilla-JS UI in `hub.js`/`common.js` reusing the existing card, overlay, and phone-tab patterns.

**Tech Stack:** Python 3.12, FastAPI, SQLite (WAL), pydantic, pytest; dependency-free vanilla JS tested via `node --test` in a vm sandbox.

**Spec:** `docs/superpowers/specs/2026-08-14-todos-design.md` (read it first; it carries the locked operator decisions and non-goals).

## Global Constraints

- No new dependencies anywhere: no pip packages, no package.json, no node_modules. Frontend stays classic-script vanilla JS.
- Public repo: no real family names, addresses, or URLs in code, tests, or fixtures. Use placeholder data like the existing tests do.
- No people linkage in this feature, per spec. Do not add person_id anywhere.
- Buckets are exactly `now`, `soon`, `later` (lowercase in storage/API; capitalized only in UI labels).
- Title validation: stripped, 1 to 120 characters. Bucket validation: one of the three values. 422 with a plain message on violation, 404 for unknown ids.
- All timestamps ISO-8601 UTC; `done_date` is the local date (app `TZ`) at completion, format `YYYY-MM-DD`. `done_at` and `done_date` are always set together or cleared together.
- When the static assets change (Task 5+), bump EVERY `?v=27` cache buster to `?v=28` in BOTH `index.html` and `admin.html` (3 references each).
- Avoid em dashes in new comments and strings (user rule); use commas, colons, or parentheses.
- Verify tests genuinely RUN. The JS suite (`tests/test_js.py`) skips loudly if neither `node` nor `docker` exists; a skip is not a pass.
- Work on a feature branch; before opening the PR run the three review agents required by CLAUDE.md (`pr-review-toolkit:silent-failure-hunter`, `pr-review-toolkit:code-reviewer`, `pr-review-toolkit:pr-test-analyzer`) on the branch diff and address real findings.

```python
# --- todos ----------------------------------------------------------------

def add_todo(conn, title: str, bucket: str) -> int:
    cur = conn.execute(
        "INSERT INTO todos(title, bucket, created_at) VALUES(?, ?, ?)",
        (title, bucket, _now_iso()))
    conn.commit()
    return int(cur.lastrowid)


def list_todos(conn) -> list[dict]:
    rows = conn.execute("SELECT * FROM todos ORDER BY created_at, id")
    return [dict(r) for r in rows]


def update_todo(conn, tid: int, **fields) -> None:
    cols = {k: v for k, v in fields.items() if k in _TODO_FIELDS}
    if not cols:
        return
    assignments = ", ".join(f"{k} = ?" for k in cols)
    conn.execute(f"UPDATE todos SET {assignments} WHERE id = ?",
                 (*cols.values(), tid))
    conn.commit()


def set_todo_done(conn, tid: int, done_date: str) -> None:
    conn.execute("UPDATE todos SET done_at = ?, done_date = ? WHERE id = ?",
                 (_now_iso(), done_date, tid))
    conn.commit()


def clear_todo_done(conn, tid: int) -> None:
    conn.execute("UPDATE todos SET done_at = NULL, done_date = NULL WHERE id = ?",
                 (tid,))
    conn.commit()


def delete_todo(conn, tid: int) -> None:
    conn.execute("DELETE FROM todos WHERE id = ?", (tid,))
    conn.commit()
```

Note: `CREATE TABLE IF NOT EXISTS` in `SCHEMA` is the whole migration; `ensure_schema` needs no changes (its `executescript(SCHEMA)` call creates the table on old DBs).

```python
"""Pure to-do visibility and grouping logic. Stdlib only, no I/O.

Conventions:
- A todo dict carries created_at (ISO-8601 UTC), done_at (ISO-8601 UTC or
  None) and done_date (local 'YYYY-MM-DD' or None). The two done fields are
  always set together or cleared together (db.set_todo_done /
  db.clear_todo_done enforce this).
- Done items linger on the main views for the rest of their local done_date,
  then drop off; recent_done keeps a 30-day restore window.
"""
from __future__ import annotations

import datetime as dt

BUCKETS = ("now", "soon", "later")


def is_visible(todo: dict, today: dt.date) -> bool:
    if todo.get("done_at") is None:
        return True
    return todo.get("done_date") == today.isoformat()


def group(todos: list[dict], today: dt.date) -> dict:
    """Visible items by bucket. Within a bucket: open items before done-today
    items, each oldest-first (created_at, then id). Rows with an unrecognized
    bucket are dropped, never crash."""
    out: dict[str, list[dict]] = {b: [] for b in BUCKETS}
    for t in todos:
        if is_visible(t, today) and t.get("bucket") in out:
            out[t["bucket"]].append(t)
    for b in BUCKETS:
        out[b].sort(key=lambda t: (t["done_at"] is not None,
                                   t["created_at"], t["id"]))
    return out


def recent_done(todos: list[dict], today: dt.date, days: int = 30) -> list[dict]:
    """Done items from the last `days` local days (today inclusive), newest
    done_at first. The restore surface."""
    lo = (today - dt.timedelta(days=days)).isoformat()
    hi = today.isoformat()
    done = [t for t in todos
            if t.get("done_date") and lo <= t["done_date"] <= hi]
    done.sort(key=lambda t: t["done_at"], reverse=True)
    return done
```

```python
# --- todos ----------------------------------------------------------------

class TodoIn(BaseModel):
    title: str
    bucket: str = "now"


class TodoPatch(BaseModel):
    title: str | None = None
    bucket: str | None = None


def _validate_todo(merged: dict) -> None:
    title = (merged.get("title") or "").strip()
    if not (1 <= len(title) <= 120):
        raise HTTPException(422, "title must be 1-120 characters")
    if merged["bucket"] not in tdlogic.BUCKETS:
        raise HTTPException(422, "bucket must be now, soon or later")


def _todo_row(c, tid: int) -> dict:
    for row in fdb.list_todos(c):
        if row["id"] == tid:
            return row
    raise HTTPException(404, "unknown todo")


@app.get("/api/todos")
def todos_list():
    c = _db()
    today = _today()
    rows = fdb.list_todos(c)
    return {"buckets": tdlogic.group(rows, today),
            "recent_done": tdlogic.recent_done(rows, today)}


@app.post("/api/todos")
def todos_add(t: TodoIn):
    c = _db()
    merged = t.model_dump()
    _validate_todo(merged)
    tid = fdb.add_todo(c, merged["title"].strip(), merged["bucket"])
    return _todo_row(c, tid)


@app.patch("/api/todos/{tid}")
def todos_patch(tid: int, t: TodoPatch):
    c = _db()
    row = _todo_row(c, tid)
    fields = t.model_dump(exclude_unset=True)
    merged = {**row, **fields}
    _validate_todo(merged)
    if "title" in fields:
        fields["title"] = fields["title"].strip()
    fdb.update_todo(c, tid, **fields)
    return _todo_row(c, tid)


@app.post("/api/todos/{tid}/complete")
def todos_complete(tid: int):
    c = _db()
    _todo_row(c, tid)
    fdb.set_todo_done(c, tid, _today().isoformat())
    return {"ok": True}


@app.delete("/api/todos/{tid}/complete")
def todos_uncomplete(tid: int):
    c = _db()
    _todo_row(c, tid)
    fdb.clear_todo_done(c, tid)
    return {"ok": True}


@app.delete("/api/todos/{tid}")
def todos_delete(tid: int):
    c = _db()
    _todo_row(c, tid)
    fdb.delete_todo(c, tid)
    return {"ok": True}
```

```js
/* Attempt a to-do write (add / move / complete / delete); returns true on
   success, false on failure. Same testable failure-detection contract as
   attemptToggle: the caller shows a toast on false, never a silent swallow. */
async function attemptTodo(path, method, body) {
  try {
    await j(path, {
      method,
      headers: body ? { 'Content-Type': 'application/json' } : undefined,
      body: body ? JSON.stringify(body) : undefined,
    });
    return true;
  } catch (e) {
    return false;
  }
}

/* The wall card's quiet overflow line: '3 soon · 2 later' from the hub
   payload's bucket lists, counting OPEN items only ('' when both empty). */
function todoCountsLine(buckets) {
  const b = buckets || {};
  const openCount = (list) => (list || []).filter((t) => !t.done_at).length;
  const parts = [];
  const soon = openCount(b.soon);
  const later = openCount(b.later);
  if (soon) parts.push(`${soon} soon`);
  if (later) parts.push(`${later} later`);
  return parts.join(' · ');
}
```

```js
/* Paint into the overlay host when it exists, else the phone tab section,
   clearing the other so #todo-add-input never exists twice in the DOM. */
function renderTodosPaint() {
  const overlayHost = document.getElementById('todos-full');
  const pageHost = document.getElementById('todos-page');
  const host = overlayHost || pageHost;
  if (!host) return;
  const other = overlayHost ? pageHost : null;
  if (other) other.innerHTML = '';
  const prev = document.getElementById('todo-add-input');
  const draft = prev ? prev.value : '';
  const wasOpen = !!document.querySelector('.todo-recent[open]');
  host.innerHTML = todosFullHtml();
  const inp = document.getElementById('todo-add-input');
  if (inp && draft) inp.value = draft;
  const recent = host.querySelector('.todo-recent');
  if (recent && wasOpen) recent.open = true;
}

async function renderTodosFull() {
  try {
    todoState.data = await j('/api/todos');
  } catch (e) { /* keep the last data (or null -> unreachable message) */ }
  renderTodosPaint();
}

function todosViewActive() {
  return openView === 'todos' || document.body.dataset.tab === 'todos';
}

  if (todosViewActive()) await renderTodosFull(); // full view, when showing
}

async function toggleTodo(id, done) {
  const ok = await attemptTodo(`/api/todos/${id}/complete`, done ? 'DELETE' : 'POST');
  if (!ok) showToast('Couldn’t save — check the hub and tap again.');
  await refreshTodos();
}

async function addTodo() {
  const input = document.getElementById('todo-add-input');
  const title = ((input && input.value) || '').trim();
  if (!title) return;
  const ok = await attemptTodo('/api/todos', 'POST',
    { title, bucket: todoState.addBucket });
  if (!ok) { showToast('Couldn’t save — check the hub and tap again.'); return; }
  if (input) input.value = '';
  await refreshTodos();
}

async function moveTodo(id, bucket) {
  const ok = await attemptTodo(`/api/todos/${id}`, 'PATCH', { bucket });
  if (!ok) showToast('Couldn’t save — check the hub and tap again.');
  todoState.openId = null;
  await refreshTodos();
}

async function deleteTodo(id) {
  const ok = await attemptTodo(`/api/todos/${id}`, 'DELETE');
  if (!ok) showToast('Couldn’t save — check the hub and tap again.');
  todoState.openId = null;
```
