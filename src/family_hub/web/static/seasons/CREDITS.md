# Seasonal look artwork

Everything in this folder is either made for this project or used under a free
licence. All of it ships inside the app, so the wall never loads art from the
internet.

| File | Source | Licence |
| --- | --- | --- |
| `*-ridge-*.svg` | Generated by `scripts/gen-season-art.mjs` (this repo) | MIT, same as the app |
| `grain.svg` | Made for this project | MIT, same as the app |
| `leaf-maple.svg` | [Twemoji](https://github.com/jdecked/twemoji) 1f341 "maple leaf", fill colour removed | [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/), © Twitter, Inc and other contributors |
| `leaf-slender.svg` | [Phosphor Icons](https://phosphoricons.com) "leaf" (fill) | MIT, © Phosphor Icons |
| `mark-grains.svg` | [Phosphor Icons](https://phosphoricons.com) "grains" (fill) | MIT, © Phosphor Icons |
| `mark-evergreen.svg` | [Phosphor Icons](https://phosphoricons.com) "tree-evergreen" (fill) | MIT, © Phosphor Icons |

The shapes are used as CSS masks, so each look paints them in its own colours.
